FlyRank ML Internship Capstone

Predicting Organic Search Momentum Decay: An Honest Machine Learning Framework for Content Refresh Prioritization

Author: Ali Atayyab  |  Lane: Refresh / Content Opportunity Scoring  |  Repository: github.com/AliAtayyab/flyrank-ml-internship

Abstract

Organic search traffic decays non-linearly over time as competitor content emerges and user intent shifts, yet editorial teams rely on naive heuristics or unranked manual audits to decide what to update. This research frames content refresh prioritization as a binary decay scoring task evaluated via Precision@50. Using anonymized, enterprise multi-client search logs from the FlyRank warehouse, we benchmark hand-written threshold heuristics against tree ensemble architectures under client-holdout validation. The Gradient Boosting model achieves an 80.00% Precision@50, outperforming fixed heuristic rules by over 3x while identifying high-value pages experiencing momentum decay before complete traffic evaporation. These results provide content operations with an interpretable, prioritized action queue with distinct reason codes.

1. Introduction & Problem Statement

For enterprise SEO and editorial operations, content production accounts for substantial capital expenditure, yet content maintenance is often reactive. Pages that steadily lose position and impression volume are typically only diagnosed after revenue impact is realized.

Editorial bandwidth is constrained: an editorial team can realistically refresh only 20 to 50 URLs per cycle. The core decision is resource allocation: determining which declining URLs yield the highest return on editorial intervention. A false positive consumes writing budget on a stable page, while a false negative permanently forfeits search equity to competitors.

2. Data Contract & Public-Safe Slice

The dataset comprises anonymized Google Search Console logs provided via the FlyRank/internship-warehouse release.

  • Unit of Analysis (Grain): Exactly one row per unique URL (page_id) per client.
  • Observation Window: Mid-panel historical snapshots (30-day baseline vs. prior 30-day window) evaluated on month=2026-03.
  • Target Proxy: is_declining_label (Binary flag indicating traffic drop of >20% across observation boundaries).
  • Deliberate Exclusions: Future-window impression metrics and downstream conversion totals were strictly excluded at inference time to guarantee zero temporal leakage.

3. Methodology & Validation Design

A key failure mode in SEO machine learning is cross-client leakage: random train/test splits allow models to memorize domain-level traffic magnitude rather than generalizable decay signals.

We enforce Client-Holdout Validation (GroupSplit), ensuring that 20% of client domains are held out strictly for out-of-sample testing.

Feature Engineering

Five leak-free, decision-time features were extracted:

  1. content_age_days: CMS metadata tracking days since initial publication.
  2. impressions_prev_30d: Trailing search exposure from 31–60 days prior.
  3. impressions_last_30d: Recent search exposure from the past 30 days.
  4. drop_volume: Absolute historical impression volume lost (prev_30d - last_30d).
  5. momentum_ratio: Relative velocity ratio (last_30d / (prev_30d + 1)).

4. Results & Benchmark Comparison

Models were evaluated on the held-out client partition using Precision@50 (the proportion of genuinely declining pages in the top-50 prioritized recommendations):

5. Ranked Recommendations & Action Playbook

Raw probability scores are mapped into prioritized editorial workflows with interpretable reason codes:

Priority Tier Reason Code Trigger Signals Recommended Action
Tier 1: Immediate HIGH_VOLUME_DECAY_STALE Score > 0.80, Age > 180d, Drop > 500 impressions Full content rewrite, update statistics, refresh title tags & H2 headings.
Tier 2: Moderate MODERATE_TRAFFIC_DROP Score 0.50–0.79, Momentum < 0.70 Add internal links from newer articles, expand FAQ schema.
Tier 3: Passive ROUTINE_AUDIT Score < 0.50, Stable position Monitor only; no editorial intervention required.

6. Limitations & Observational Framing

  • Observational, Not Causal: This model identifies statistical decay patterns in historical logs; it does not claim to reverse-engineer Google's proprietary search algorithms.
  • Seasonality Blindness: A 30-day window can misclassify predictable holiday or seasonal demand drops as content obsolescence.
  • Data Privacy: All client IDs, page paths, and proprietary domain metrics remain fully anonymized.
